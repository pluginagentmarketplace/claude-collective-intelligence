## Executive Summary

9 plugins had hooks.json format errors causing Claude Code `/plugin` menu to show validation errors. All were fixed by migrating to v2.0.27+ format with nested `hooks` array.

---

## Error Pattern

**Error Message:**
```
Invalid input: expected array, received undefined
```

**Error Path:**
```
["hooks", "SessionStart", 0, "hooks"]
```

**Root Cause:**
Claude Code v2.0.27+ changed hooks.json schema to require:
1. Matcher object with `"matcher"` field (string)
2. Nested `"hooks"` array inside matcher
3. Hook objects with explicit `"type": "command"` field
4. Removed `"once"` field from schema

## Format Migration

### OLD Format (WRONG - pre v2.0.27)

```json
{
  "hooks": {
    "SessionStart": [
      {
        "command": "echo 'Plugin ready!'",
        "once": true,
        "timeout": 2000
      }
    ]
  }
}
```

### NEW Format (CORRECT - v2.0.27+)

```json
{
  "hooks": {
    "SessionStart": [
      {
        "matcher": "*",
        "hooks": [
          {
            "type": "command",
            "command": "echo 'Plugin ready!'",
            "timeout": 2000
          }
        ]
      }
    ]
  }
}
```

---

## Key Schema Changes (v2.0.27+)

| Field | Old | New | Required |
|-------|-----|-----|----------|
| `matcher` | N/A | String ("*", "Edit", etc.) | YES |
| `hooks` | N/A | Array of hook objects | YES |
| `type` | Implicit | Explicit ("command") | YES |
| `once` | Supported | REMOVED | N/A |

## Prevention Checklist

When creating new hooks.json:

- [ ] Use `"matcher": "*"` (or specific tool name)
- [ ] Nest hook objects inside `"hooks": [...]` array
- [ ] Add explicit `"type": "command"` to each hook
- [ ] Do NOT use `"once"` field (deprecated)
- [ ] Validate with: `claude /plugin` menu
